## 📖 Sobre o projeto

O **Sorteador de Números** é um projeto desenvolvido durante o curso **Lógica de programação: praticando com desafios**, da Alura.

O objetivo foi colocar em prática conceitos fundamentais de JavaScript, trabalhando com manipulação de elementos HTML, estruturas de repetição, condicionais, arrays e geração de números aleatórios.

O projeto também proporcionou experiências práticas de identificação e correção de erros utilizando as ferramentas de desenvolvedor do navegador.

---

## 🚀 Funcionalidades

- 🎯 Definir a quantidade de números que serão sorteados.
- 🔢 Informar o intervalo mínimo e máximo do sorteio.
- 🎲 Gerar números aleatórios dentro do intervalo escolhido.
- 🔄 Evitar números repetidos durante o sorteio.
- 📋 Exibir os números sorteados diretamente na página.
- ♻️ Reiniciar o sorteio e limpar os campos preenchidos.
- 🔘 Alterar dinamicamente o estado visual do botão de reinício.

## 🎮 Como utilizar

1. Abra o projeto no navegador.
2. Informe a quantidade de números que deseja sortear.
3. Digite o número inicial no campo **Do número**.
4. Digite o número final no campo **Até o número**.
5. Clique no botão **Sortear**.
6. Visualize os números sorteados na tela.
7. Utilize o botão **Reiniciar** para começar um novo sorteio.

**Observação:** a quantidade solicitada deve ser menor ou igual à quantidade de números disponíveis no intervalo, para que o sorteio sem repetição seja possível.

## 🧠 Conhecimentos praticados

Durante o desenvolvimento deste projeto, pratiquei:

- Manipulação do DOM com `document.getElementById()`.
- Recuperação de valores utilizando `.value`.
- Conversão de strings para números com `parseInt()`.
- Utilização de Template Strings.
- Estruturas condicionais `if/else`.
- Estruturas de repetição `for` e `while`.
- Manipulação de arrays com `push()` e `includes()`.
- Geração de números aleatórios com `Math.random()` e `Math.floor()`.
- Alteração dinâmica do conteúdo HTML com `innerHTML`.
- Manipulação de classes CSS utilizando `classList`.
- Depuração de código com o console do navegador.

## 💡 Aprendizados durante o desenvolvimento

Um dos desafios encontrados foi implementar corretamente a funcionalidade do botão **Reiniciar**.

Durante os testes, identifiquei que havia uma diferença entre os nomes das classes CSS utilizadas no HTML e no JavaScript.

Utilizando o console do navegador e analisando as classes dos elementos, consegui identificar o problema e realizar a correção.

Essa experiência reforçou a importância da atenção aos detalhes, da depuração e da compreensão de como HTML, CSS e JavaScript trabalham juntos.
